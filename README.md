# QueryPath — интерактивный тренажёр по SQL

Мини-клон формата Coddy (путь → практика → профиль), только для SQL. Чистый HTML/CSS/JS, без сборки — можно открыть локально или выложить на GitHub Pages.

## Запуск

Локально (нужен любой статический сервер, т.к. используются ES-модули):

```bash
cd sql-coddy
python3 -m http.server 8080
# открыть http://localhost:8080
```

### GitHub Pages
1. Залейте содержимое папки `sql-coddy/` в репозиторий.
2. Settings → Pages → Source: ветка `main`, папка `/ (root)`.
3. Готово — сайт появится на `https://username.github.io/repo/`.

## Структура

```
index.html            — шелл приложения
style.css              — вся стилистика (тёмная тема)
ai-worker.js            — Cloudflare Worker: общий прокси к Anthropic API для Bugsy
js/main.js               — роутер (Путь / Практика / Профиль)
js/state.js               — прогресс, монеты, стрик (localStorage)
js/sqlEngine.js            — выполнение SQL через sql.js (SQLite в браузере)
js/pathPage.js, practicePage.js, profilePage.js, topbar.js   — три экрана
js/lessonView.js, taskView.js, practiceTaskOverlay.js, aiAssistant.js — теория+тест+код, карточка задачи, ИИ-чат
data/lessons.js          — контент Пути (главы: теория, тест, задача)
data/practice.js         — банк задач для Практики
```

Все JS-файлы — плоским списком в одной папке `js/`, без вложенных подпапок: так их проще загружать по одной на GitHub через телефон (папка = один экран "Upload files").

## Как добавить новую главу в Путь

Откройте `data/lessons.js`, скопируйте объект `s1c1` целиком и измените:
- `id`, `chapter`, `title`
- `theory` — массив слайдов (`type: 'text'` с полем `html`, опционально `code`; или `type: 'table'`)
- `quiz` — вопросы `type: 'single'` (варианты + правильный индекс) или `type: 'fillblank'` (пропуски с вариантами)
- `task` — таблицы/датасеты и `solutionQuery` (эталонный SQL, с которым сравнивается ответ ученика)

## Как добавить задачу в Практику

Откройте `data/practice.js`, скопируйте один из объектов и измените поля (`topic`, `difficulty`, датасет, `solutionQuery`).

## Монеты

За урок начисляется:
- 0 ошибок (в тесте и в задаче) → **10 монет**
- 1 ошибка → **7 монет**
- 2+ ошибок → **5 монет**

Логика — в `js/components/lessonView.js`, функция `coinsForErrors`.

## ИИ-ассистент Bugsy

Сайт статический, поэтому секретный API-ключ нельзя спрятать в браузере. Два варианта настраиваются в Профиле:

1. **Общий прокси (рекомендуется для тебя + близких)** — разверни `ai-worker.js` как бесплатный Cloudflare Worker (инструкция в начале файла), впиши его URL в Профиль → ИИ-ассистент. Один ключ на всех, никто его не видит.
2. **Свой API-ключ** — каждый человек вводит собственный ключ Anthropic в Профиле, ключ хранится только в его браузере.

## Типы вопросов в тесте

- `single` — выбор одного варианта из списка
- `fillblank` — заполнить пропуски в SQL-запросе, каждый пропуск — свой набор кнопок-вариантов
- `truefalse` — Истина/Ложь
