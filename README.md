# QueryPath — интерактивный тренажёр по SQL

Мини-клон формата Coddy (путь → практика → профиль), только для SQL. Чистый HTML/CSS/JS, без сборки — можно открыть локально или выложить на GitHub Pages.

## Запуск

Локально (нужен любой статический сервер, т.к. используются ES-модули):

```bash
cd sql-coddy
python3 -m http.server 8080
# открыть http://localhost:8080
```

### GitHub Pages
1. Залейте содержимое папки `sql-coddy/` в репозиторий.
2. Settings → Pages → Source: ветка `main`, папка `/ (root)`.
3. Готово — сайт появится на `https://username.github.io/repo/`.

## Структура

```
index.html            — шелл приложения
style.css              — вся стилистика (тёмная тема + альтернативные темы)
ai-worker.js            — Cloudflare Worker: общий прокси к Anthropic API для Bugsy
js/main.js               — роутер (Путь / Практика / Профиль)
js/state.js               — прогресс, монеты, рубины, миссии, инвентарь (localStorage)
js/theme.js               — применение выбранной темы оформления
js/sqlEngine.js            — выполнение SQL через sql.js (SQLite в браузере)
js/pathPage.js, practicePage.js, profilePage.js, topbar.js   — экраны
js/shopPage.js             — магазин (аватары/рамки/темы)
js/lessonView.js, taskView.js, practiceTaskOverlay.js, aiAssistant.js — теория+тест+код, карточка задачи, ИИ-чат
data/lessons.js          — контент Пути (главы: теория, тест, задача)
data/practice.js         — банк задач для Практики
data/shop.js             — каталог магазина
```

Все JS-файлы — плоским списком в одной папке `js/`, без вложенных подпапок: так их проще загружать по одной на GitHub через телефон (папка = один экран "Upload files").

## Как добавить новую главу в Путь

Откройте `data/lessons.js`, скопируйте объект `s1c1` целиком и измените:
- `id`, `chapter`, `title`
- `theory` — массив слайдов (`type: 'text'` с полем `html`, опционально `code`; или `type: 'table'`)
- `quiz` — вопросы `type: 'single'` (варианты + правильный индекс) или `type: 'fillblank'` (пропуски с вариантами)
- `task` — таблицы/датасеты и `solutionQuery` (эталонный SQL, с которым сравнивается ответ ученика)

## Как добавить задачу в Практику

Откройте `data/practice.js`, скопируйте один из объектов и измените поля (`topic`, `difficulty`, датасет, `solutionQuery`).

## Монеты

За урок начисляется:
- 0 ошибок (в тесте и в задаче) → **10 монет**
- 1 ошибка → **7 монет**
- 2+ ошибок → **5 монет**

Логика — в `js/components/lessonView.js`, функция `coinsForErrors`.

## ИИ-ассистент Bugsy

Сайт статический, поэтому секретный API-ключ нельзя спрятать в браузере. Два варианта настраиваются в Профиле:

1. **Общий прокси (рекомендуется для тебя + близких)** — разверни `ai-worker.js` как бесплатный Cloudflare Worker (инструкция в начале файла), впиши его URL в Профиль → ИИ-ассистент. Один ключ на всех, никто его не видит.
2. **Свой API-ключ** — каждый человек вводит собственный ключ Anthropic в Профиле, ключ хранится только в его браузере.

## Структура пути (зигзаг)

Каждая обычная глава (не чекпоинт) рендерится как **3 отдельных узла**: Теория → Тест → Задача, друг за другом по горизонтали, с чередованием направления по рядам (змейка), как в оригинале. Чекпоинты («Трофей главы») остаются одним узлом с кратким повторным тестом.

Прогресс по каждой фазе хранится отдельно (`state.lessonPhases`), монеты начисляются один раз — при завершении фазы «Задача», с учётом ошибок, накопленных на тесте и в самой задаче.

## Типы вопросов в тесте

- `single` — выбор одного варианта из списка
- `fillblank` — заполнить пропуски в SQL-запросе, каждый пропуск — свой набор кнопок-вариантов
- `truefalse` — Истина/Ложь
- `findline` — кликнуть на строку кода с синтаксической ошибкой

## Структура главы (по образцу Coddy)

Каждый `Раздел` (SECTIONS) состоит из нескольких `Глав` — сгруппированы полем `module` у объектов в LESSONS. Путь автоматически рисует текстовый разделитель между главами (например «Введение» → «Условия»). Глава обычно заканчивается чекпоинтом (`kind: 'checkpoint'`) — трофей-нодой с обзорным тестом по всей главе.

## Практика: накопительные задачи

Банк практики (`data/practice.js`) организован так, чтобы после каждой новой темы в Пути появлялись задачи и на неё саму, и на неё в связке с ранее изученными темами (например «DISTINCT + WHERE», «AND + ORDER BY», «LIKE + IN + ORDER BY»). Чтобы добавить новую комбинацию, скопируйте существующий объект и укажите `topic` — тот же принцип, что и раньше.

## Монеты, рубины, миссии, магазин

- **Монеты** — за уроки на Пути (10/7/5 в зависимости от ошибок).
- **Рубины** — премиум-валюта, начисляется за выполнение ежедневных миссий (Профиль → «Ежедневные миссии»). Список миссий — в `js/state.js`, константа `DAILY_MISSION_DEFS`. Прогресс считается автоматически (пройденные уроки, решённые задачи практики, заработанные за день монеты) и сбрасывается каждый новый день.
- **Магазин** (`js/shopPage.js` + каталог `data/shop.js`) — три категории: аватары, рамки, темы. У каждого айтема есть редкость (`common/rare/epic/legendary/mythical`); товары common/rare/epic стоят монеты, legendary/mythical — рубины. Бесплатные айтемы (без рамки, 6 базовых аватаров, тёмная и светлая темы) выданы всем по умолчанию. Чтобы добавить новый товар — допишите объект в `SHOP_ITEMS`.
- **Темы** переключаются мгновенно через CSS-переменные (`style.css`, блок «Alternate themes») — переопределяются классом на `<body>`, который выставляет `js/theme.js` при загрузке и при смене темы в магазине.

## Обновление сайта и кэш браузера

В `index.html` версии `style.css`/`js/main.js` подключены с `?v=N` — при каждой следующей поставке файлов стоит увеличивать это число, чтобы браузеры гарантированно подтянули новые версии. Также в Профиль → Настройки есть кнопка «Обновить сайт» — она делает принудительную перезагрузку с новым параметром в адресе, чтобы обойти локальный кэш телефона/браузера.
